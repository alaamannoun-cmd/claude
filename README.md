# مجلس — Majlis AI Mentors ✦

**فريق مدرّبيك الشخصي بالذكاء الاصطناعي.** تصمّم مدرّبين بشخصيات وأشكال تختارها، لكل واحد **ملف ذاكرة خاص**، ويعملون معاً تحت إدارة **مدير المجلس** الذي يوزّع الشغل بينهم، ويرتّب لك **مسارات تعلّم** منظّمة، ويذكّرك بأهدافك.

📄 **الفكرة الكاملة:** [`docs/CONCEPT.md`](docs/CONCEPT.md)

---

## التشغيل (دقيقة واحدة)

المتطلبات: **Node.js 18+** فقط، بدون أي `npm install` (لا توجد مكتبات خارجية).

```bash
node server.js
# افتح http://localhost:3000
```

- عند أول تشغيل يرحّب بك **سَنَد** (مدير المجلس)، ثم يطلب **مفتاح DeepSeek**. الصقه هناك، أو من **الإعدادات** لاحقاً.
- بدون مفتاح؟ اختر **«جرّب بالوضع التجريبي»**: كل الميزات تعمل بردود توضيحية، وهو مفيد للعرض والتطوير.

### إضافة مفتاح DeepSeek
عندك طريقتان:
1. **من داخل التطبيق:** الإعدادات ← «اتصال DeepSeek». يُحفظ المفتاح في `data/config.json` على السيرفر المحلي فقط، ولا يصل للمتصفح أبداً.
2. **من ملف `.env`:**
   ```bash
   cp .env.example .env
   # ثم ضع المفتاح:  DEEPSEEK_API_KEY=sk-...
   ```

> ⚠️ ملفّا `data/` و`.env` مستثنيان من git (`.gitignore`)، فلا تضع المفتاح في أي ملف آخر داخل المستودع.

### أوامر مفيدة
```bash
npm start          # تشغيل عادي
npm run dev        # إعادة تشغيل تلقائية عند تعديل كود السيرفر
npm run demo       # وضع تجريبي إجباري (MOCK=1)
PORT=4000 node server.js
HOST=0.0.0.0 node server.js   # لفتحه من موبايلك على نفس الشبكة
```

## الرفع على استضافة

1. **الاستضافة لازم تدعم Node.js 18 أو أحدث**: سيرفر VPS، أو cPanel فيه «Setup Node.js App»، أو خدمات مثل Render وRailway. الاستضافة اللي بتدعم PHP فقط ما بتشغّله.
2. ارفع الملفات وفك الضغط. **ما في داعي لـ `npm install`**.
3. انسخ `.env.example` إلى `.env` واملأ:
   - `DEEPSEEK_API_KEY`: مفتاحك (أو أضفه لاحقاً من الإعدادات).
   - **`APP_PASSWORD`: ضروري على الإنترنت.** بدونه أي شخص بيفتح الرابط بيقدر يستخدم رصيدك ويشوف بياناتك.
   - `HOST=0.0.0.0` إذا كان سيرفر VPS مباشر. في cPanel اتركه كما هو.
   - `PORT` حسب ما تحدده الاستضافة.
4. ملف التشغيل هو `server.js`، وبـ cPanel بيتحط بخانة «Application startup file».
5. تأكد إن مجلد `data/` قابل للكتابة، لأن فيه الذاكرة والمحادثات والمفتاح. خذ منه نسخة احتياطية بشكل دوري.
6. فعّل **HTTPS** (مثلاً Let's Encrypt)، لأن كلمة المرور بتنبعت مع كل طلب.

## ماذا بداخله؟

| الشاشة | الوظيفة |
|---|---|
| **الرئيسية** | موجز اليوم من المدير (أولويات مرتّبة)، اسأل المجلس، المستوى والنقاط، سلسلة الأيام، فريقك، الدرس التالي، الأهداف، وخريطة النشاط |
| **جلسة تدريب (1:1)** | محادثة ببث مباشر؛ أفاتار يفكّر ويتكلم؛ شارات «🧠 تذكّر…» عند تحديث الذاكرة؛ اقتراح أهداف من الحديث؛ أزرار سريعة ذكية؛ وضع الدرس؛ افتتاح جلسة استباقي بعد الغياب |
| **المجلس** | «اسأل المجلس»: المدير يحلّل ويوزّع المهام، والمدرّبون يجيبون ويبنون على بعض، ثم خلاصة وخطة ← تحويلها لهدف. «جلسة نقاش»: نقاش أو مناظرة أو عصف ذهني أو تخطيط بين 2–4 مدرّبين، مع إمكانية التدخّل |
| **المسارات** | منهج مخصّص (وحدات ← دروس ← تمارين ← مصادر) على شكل خريطة رحلة تفاعلية |
| **الأهداف** | هدف + مدرّب مسؤول + موعد + تذكير؛ «رتّب الخطة» تحوّله لـ SMART بمحطات وخطوة لليوم |
| **الذاكرة** | ملف كل مدرّب مقسّم لأقسام: تعديل، حذف، إضافة، تحرير خام، تصدير `.md`، وتصفير |
| **صانع المدرّبين** | 8 قوالب جاهزة؛ الهوية والتخصص؛ 5 منزلقات شخصية تتحول لسلوك تعليمي؛ أسلوب تدريس ولهجة؛ **22 شخصية بشرية ثلاثية الأبعاد** (بحجاب، بشماغ، رسمي، طبي، رياضي…) مع نظارات وتعبير وإضاءة وخلفية، ومعاينة حيّة؛ وصايا دائمة |
| **الإعدادات** | مفتاح ونموذج DeepSeek واختبار الاتصال، ملفك الشخصي، تخصيص المدير، الأصوات، الوضع الليلي الاختياري، الإشعارات، وتصدير البيانات أو حذفها |

## الأفاتار ثلاثي الأبعاد

- **الشخصيات:** 22 إنساناً واقعياً من مكتبة [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox) (رخصة MIT، مسموحة تجارياً). تم تحويلها من FBX إلى GLB مضغوط (دمج الرؤوس، 55 تعبير وجه ARKit وVisemes، خامات WebP، ضغط meshopt). الرخصة والإسناد في [`public/avatars/LICENSE.md`](public/avatars/LICENSE.md).
- **المحرّك** (`public/js/avatar3d.js`):
  - **الإضاءة:** مواد PBR (جلد بلمعة ناعمة، شعر بشفافية، قماش)، وإضاءة استوديو + HDRI.
  - **الحياة:** رمش عشوائي، تنفّس، حركة رأس، نظرات سريعة للعين، ومتابعة الماوس.
  - **المزاج:** يفكّر، سعيد، يستمع، يتكلم.
  - **مزامنة الشفاه:** من النص المتدفق مباشرة (عربي وإنجليزي).
- **الأداء:**
  - حلقة رسم واحدة للجميع.
  - إيقاف الرسم خارج الشاشة.
  - 30fps وقت الهدوء.
  - تخفيف تلقائي على الأجهزة بلا كرت شاشة.
  - صور مصغّرة ثابتة للأماكن الصغيرة، ولقطات حيّة مخزّنة مؤقتاً عند إضافة نظارات.
- **إضافة شخصيات جديدة:** أي GLB بهيكل Rocketbox/Biped وأشكال ARKit يعمل مباشرة؛ أضفه في `avatars/models/` وسجّله في `MODELS` داخل `public/js/catalog.js`.

```
server.js                 ← خادم HTTP بلا اعتماديات (ملفات ثابتة + API + بث SSE)

  llm.js                  ← عميل DeepSeek (OpenAI-compatible): بث، JSON mode، أخطاء ودّية
  prompts.js              ← كل البرومبتات: المدرّب، محرّك الذاكرة، المدير، المجلس، المسارات…
  agents.js               ← تنسيق الوكلاء (حقيقي أو تجريبي) + تنظيف مخرجات JSON
  mock.js                 ← الوضع التجريبي
  memory.js               ← قراءة/تحديث memory.md سطراً بسطر (يحافظ على تعديلاتك اليدوية)
  db.js / store.js        ← تخزين ملفات JSON/Markdown بكتابة ذرّية وأقفال
  routes.js               ← نقاط الـ API
public/
  index.html, css/app.css ← الواجهة (عربي RTL، فاتح افتراضياً، متجاوبة مع الموبايل)
  js/avatar3d.js          ← محرّك الأفاتار ثلاثي الأبعاد (Three.js): حياة، نظرات، مزاج، مزامنة شفاه، ولقطات
  js/avatar.js            ← إعدادات الأفاتار (مشتركة مع السيرفر) + تحويل الإعدادات القديمة
  avatars/models/*.glb    ← 22 شخصية Rocketbox محوّلة ومضغوطة (~1MB لكل شخصية)
  avatars/thumbs/*.webp   ← صور مصغّرة جاهزة (للقوائم والأماكن الصغيرة)
  vendor/three/           ← Three.js r170 (نسخة محلية، بلا CDN)
  js/catalog.js           ← الشخصيات، اللهجات، الأساليب، المستويات (مشترك مع السيرفر)
  js/templates.js         ← قوالب المدرّبين + المدير الافتراضي
  js/views/*.js           ← الشاشات
docs/CONCEPT.md           ← وثيقة الفكرة والمنتج
```

## الأمان في هذه المرحلة
المرحلة الحالية لإثبات الكونسبت، ومع ذلك:
- مفتاح الـ API **على السيرفر فقط**، والواجهة ترى تلميحاً مخفياً منه (`sk-…abcd`).
- السيرفر يستمع على `127.0.0.1` افتراضياً (جهازك فقط).
- كل مخرجات الذكاء الاصطناعي تُعرض عبر محوّل Markdown **يهرّب HTML** (لا XSS).
- المعرّفات في المسارات مُتحقَّق منها (لا path traversal)، وحجم الطلبات محدود.

خطة الحماية الكاملة موجودة في قسم «خارطة الطريق» في [`docs/CONCEPT.md`](docs/CONCEPT.md#10-خارطة-الطريق): حسابات المستخدمين، خزنة الأسرار، حدود الاستخدام، التشفير، والحماية من Prompt Injection.
