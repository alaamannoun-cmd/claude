# Sakura Michi · طريق الساكورا

لعبة ثلاثية الأبعاد تفاعلية مبنية بـ three.js: تقود فيها درّاجة هوائية عبر وادٍ ياباني في موسم تفتّح الساكورا. كل شيء في المشهد مولَّد برمجياً داخل المتصفح، بلا أي ملفات خارجية أو صور أو نماذج جاهزة.

A 3D bicycle ride through a Japanese spring valley, built with three.js. Everything (terrain, trees, buildings, the rider and the bike, sounds and music) is generated procedurally in the browser.

## التشغيل

الملف الجاهز: [`dist/sakura-michi.html`](dist/sakura-michi.html). ملف HTML واحد مستقل (حوالي 830 كيلوبايت) يحتوي على three.js وكل كود اللعبة. افتحه مباشرة في Chrome أو Edge أو Firefox أو Safari، ولا يحتاج إلى إنترنت أو خادم.

يُفضَّل حاسوب ببطاقة رسوميات. اللعبة تختار الجودة تلقائياً، وتخفّضها بنفسها إذا انخفض معدّل الإطارات. يمكنك أيضاً تغييرها من شاشة البداية أو بمفتاح `Q`.

## النشر على Netlify

- **رفع يدوي:** شغّل `npm run netlify` (أو استخدم الملف الجاهز `sakura-michi-netlify.zip`)، ثم اسحب ملف الـ zip إلى [app.netlify.com/drop](https://app.netlify.com/drop). الملف يحتوي على `index.html` و`_headers` في جذره مباشرة.
- **نشر تلقائي من GitHub:** اربط المستودع بـ Netlify. ملف `netlify.toml` يحدّد أمر البناء ومجلد النشر `dist/netlify`.

## ما في الوادي

- طريق دائري طوله حوالي 2.4 كم يمرّ بـ:
  - ممرّ أشجار الساكورا على ضفة النهر
  - حقول النانوهانا الصفراء
  - بحيرة تعكس جبل فوجي، مع بوابة توري قائمة في الماء
  - جسر أحمر مقوّس
  - تلّة الباغودا ذات الطوابق الخمسة
  - غابة الخيزران
  - ممرّ من 31 بوابة توري
  - معبد صغير
  - قرية فيها بيوت بسقوف من القرميد والقشّ، وحقول أرز مغمورة بالماء
  - بساط الشيبازاكورا الملوّن
- ماء عاكس حقيقي، وبتلات تتساقط وتطفو على النهر، وعشب وأشجار تتمايل مع الريح، وفراشات وطيور، ويراعات في الليل.
- الراكبة لها وجه وشعر وحقيبة ظهر ووشاح. الساقان والذراعان تتحرّكان بالحركيات العكسية (IK) مع البدّالات والمقود. تميل مع الدرّاجة في المنعطفات، وتقف على البدّالات عند التسارع، وتنزل قدمها إلى الأرض عند التوقّف، وتلتفت لتتأمل المناظر. الوشاح وذيل الشعر يتحرّكان بفيزياء حبال.
- أصوات مولّدة: ريح، ونهر، وعجلات، وطقطقة الدولاب الحرّ، والجرس، وعصافير، وصراصير الليل، ولحن كوتو هادئ.

## البناء من المصدر

```bash
npm install
npm run build        # يكتب dist/sakura-michi.html
```

`node scripts/build.mjs --dev` يبني نسخة غير مضغوطة لتسهيل التصحيح. `scripts/shot.mjs` يلتقط صوراً للّعبة في Chromium بدون واجهة، وهو ما استُخدم لاختبار المشاهد.

### هيكل الكود

```
src/
  main.js              ربط الأنظمة وحلقة اللعبة
  core/                الضباب، الخامات، المعالجة اللاحقة، الكاميرا، الإدخال، الصوت، الجودة
  world/               التضاريس، الطريق، النهر والبحيرة، السماء، الجبال البعيدة، توزيع العناصر، الحيوانات
  veg/                 الأشجار (ساكورا، قيقب، صنوبر، أرز)، العشب، الخيزران، البتلات، بساط الزهور
  structures/          التوري، الجسور، الباغودا، الفوانيس الحجرية، المعبد، البيوت، حقول الأرز
  bike/                نموذج الدرّاجة، الراكبة وحركتها، فيزياء القيادة
  ui/                  واجهة HTML/CSS والعدّاد والخريطة المصغّرة
```
