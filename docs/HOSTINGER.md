# رفع «مجلس» على Hostinger (استضافة PHP)

هذه النسخة تعمل على أي استضافة PHP عادية (Hostinger، cPanel…) **بدون Node.js وبدون تثبيت أي شيء**.
الواجهة نفسها (الأفاتارات ثلاثية الأبعاد، المجلس، المسارات…)، والخادم مكتوب بـ PHP.

## المتطلبات
- PHP 8.0 أو أحدث (يفضّل 8.2) مع إضافات `curl` و`mbstring`، وهي مفعّلة افتراضياً في Hostinger.
- التطبيق يعمل على **جذر دومين أو دومين فرعي** (مثل `majlis.example.com`)، وليس داخل مجلد فرعي مثل `example.com/majlis`.

## الخطوات (5 دقائق)
1. من **hPanel ← File Manager** ادخل مجلد `public_html` الخاص بالدومين (أو الدومين الفرعي).
2. ارفع ملف `majlis-hostinger.zip` ثم اضغط عليه بالزر الأيمن ← **Extract**، واستخرجه **مباشرة داخل `public_html`**.
   - تأكد إن `index.html` و`.htaccess` ومجلد `api` صاروا مباشرة داخل `public_html`، مش داخل مجلد إضافي.
3. افتح الملف `api/config.php` للتعديل واكتب:
   - `DEEPSEEK_API_KEY`: مفتاحك (أو اتركه فارغاً وأضفه لاحقاً من شاشة الإعدادات داخل التطبيق).
   - **`APP_PASSWORD`: كلمة مرور.** ضروري، لأن بدونها أي شخص يعرف الرابط يقدر يستخدم رصيدك ويشوف بياناتك.
4. من **hPanel ← Advanced ← PHP Configuration** اختر PHP 8.2 أو أحدث (8.0 كحد أدنى).
5. فعّل **SSL** للدومين (مجاني في Hostinger) وافتح الموقع بـ `https://`.

جاهز. افتح الدومين، ادخل كلمة المرور، وابدأ.

## أين تُحفظ البيانات؟
- في مجلد `data/` بجانب `index.html`: ذاكرة كل مدرّب (`data/mentors/<id>/memory.md`)، والمحادثات، والأهداف، والمسارات.
- المجلد محمي من التصفّح المباشر (`.htaccess`).
- للأمان الأعلى، ضع مساراً خارج `public_html` في `DATA_DIR` داخل `api/config.php`.
- **خذ نسخة احتياطية** من مجلد `data` بشكل دوري (أو من الإعدادات ← تصدير كل البيانات).

## حل المشاكل
| المشكلة | الحل |
|---|---|
| صفحة 404 عند الإرسال أو الرسائل لا تصل | تأكد أن ملف `.htaccess` موجود في `public_html` (الملفات المخفية تظهر من إعدادات File Manager). |
| «تعذّر إنشاء مجلد البيانات» | أعطِ `public_html` صلاحية الكتابة (755)، أو أنشئ مجلد `data` يدوياً بصلاحية 755. |
| الرد يظهر دفعة واحدة بدل الكتابة الحيّة | بعض إعدادات الاستضافة تؤخّر البث. التطبيق يعمل بشكل طبيعي، لكن الرد يظهر عند اكتماله. |
| «مفتاح DeepSeek غير صالح» | راجع المفتاح في `api/config.php` أو في الإعدادات داخل التطبيق. |
| الرد أو جلسة المجلس تنقطع في منتصفها | من **hPanel ← Advanced ← PHP Configuration ← PHP Options** ارفع `max_execution_time` إلى 300. |
| تغيير كلمة المرور | عدّل `APP_PASSWORD` في `api/config.php`. كل الأجهزة المسجّلة تخرج تلقائياً وتدخل بالكلمة الجديدة. |
